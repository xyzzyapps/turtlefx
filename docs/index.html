01 / THINK LIKE A TURTLE

Push-Based Drawing Over Pull-Based Shaders

Normally, GPU shaders make you think backwards: for every single pixel on screen, you write distance equations to figure out its color. Logo flips that around. You steer an invisible robot turtle holding a pen, and TurtleFX translates your commands into GPU Signed Distance Fields automatically.

Draw a Glowing Square in 4 Lines 
mode 2d
fx bloom(strength: 0.6)

on frame(dt)
  clear #06070d
  color #38bdf8
  pen_width 3
  glow 0.8

  repeat 4 [
    fd 80
    rt 90
  ]
end

Line-by-Line Breakdown

  • mode 2d — Enables smooth, anti-aliased vector rendering.
  • fx bloom(...) — Tells the hidden GPU shader to run 2-pass glow.
  • on frame(dt) — Runs 60 times per second to emit each frame.
  • repeat 4 [ ... ] — Loops everything inside [ ] four times.
  • fd 80 / rt 90 — Move forward 80 units, turn right 90°.
Challenge: Change repeat 4 to repeat 5 and rt 90 to rt 144 in the sandbox above to draw a 5-point star.
02 / MOTION & BRANCHING

Animation, Rainbow Color & branch [ ... ]

TurtleFX exposes a live time variable (seconds since start) and wave functions like sin(time). Wrap any sub-drawing in branch [ ... ] to save the turtle's position, angle, and color before entering — and automatically restore them on exit.

Spinning Rainbow Pinwheel 
mode 2d
fx bloom(strength: 0.6)

on frame(dt)
  clear #06070d
  rt time * 40           ; spin the whole wheel

  repeat 12 with i [
    branch [
      rt i * 30          ; 12 spokes, 30 deg apart
      color hsl(i * 30 + time * 80, 100%, 60%)
      glow 0.7
      fd 70 + sin(time * 4 + i) * 25
      dot 8
    ]
  ]
end

Key Ideas

  • repeat 12 with i — Binds loop index i from 0 to 11.
  • hsl(hue, 100%, 60%) — Cycles through the color wheel in degrees.
  • branch [ ... ] — Every spoke starts cleanly at the origin without manual backtracking.
  • dot 8 — Stamps a glowing circle of radius 8 at the spoke tip.
03 / ARCADE GAMEPLAY

Lists, Hitboxes & Destroying Enemies

Real games need persistent state across frames. Declare a 1D list like let enemy_alive = [1, 1, 1, 1, 1, 1], read or mutate element i with enemy_alive[i], and test hitboxes using abs(...).

Hit Detection in 01_retro_arcade.logo 
; 1 = alive, 0 = destroyed
let enemy_alive = [1, 1, 1, 1, 1, 1]

; Inside on frame(dt):
if enemy_alive[i] == 1 [
  if abs(bolt_x[b] - ex) < 9 and abs(bolt_y[b] - ey) < 8 [
    enemy_alive[i] = 0    ; destroy this enemy
    bolt_y[b] = -20       ; consume the laser
    boom_t[i] = 0.35      ; start radial turtle explosion
  ]
]

Why abs(bolt_x[b] - ex) < 9 Works

abs(...) computes absolute distance without caring whether the bolt is left or right of the enemy. Checking both X (< 9 px) and Y (< 8 px) forms a fast axis-aligned bounding box (AABB) collision check.

04 / 3D WORLDS & RETRO CROSSOVER

Switch to 3D SDF Raymarching (or GameBoy 3D)

Switch to mode 3d and add airplane-style turns: pitch (nose up/down), yaw (left/right), and roll (barrel roll). TurtleFX switches to a 3D SDF raymarcher supporting clay blending (smooth), boolean holes (carve), and soft shadows.

Carve a 3D Archway 
mode 3d
fx bloom(strength: 0.55)

at -2 1.4 0 [
  material matte(#94a3b8)
  box(2.1, 2.5, 0.85)
  carve [
    at -2 0.45 0 [ pitch 90  capsule(1.3, 0.62) ]
  ]
]
2-Line GameBoy 3D Mode 
; Add these 2 lines to ANY 3D scene:
fx retro(320, 180, dither: bayer, palette: gameboy)

05 / QUICK REFERENCE

Modern Logo Cheat Sheet

Turtle Moves

  • fd 50 / bk 50 — forward / back
  • rt 90 / lt 90 — right / left
  • pu / pd — pen up / down
  • pitch / yaw / roll — 3D turns

Shapes & Style

  • dot 10, rect 20 10
  • fill [ ... ] — concave polygon
  • color #ff004d, hsl(h, s, l)
  • pen_width 3, glow 0.8

3D Primitives

  • sphere(r), box(w, h, d)
  • capsule(len, r), torus(R, r)
  • smooth 0.5 [ ... ] — blend
  • carve [ ... ] — subtract

State & Control

  • let x = 10, let a = [1, 2]
  • if key("space") [ ... ]
  • repeat 8 with i [ ... ]
  • branch [ ... ], at x y [ ... ]
