MISSION 01

Think Like a Turtle (Not a Math Textbook)

Normally, GPU shaders make you think backwards: for every single pixel on the screen, you write equations to figure out what color it should be.

Logo flips that around. You control an invisible robot turtle holding a pen. You tell it where to walk and turn, and TurtleFX translates your steps into GPU shaders automatically.

Draw a Glowing Square in 4 Lines 
mode 2d
fx bloom(strength: 0.6)

on frame(dt)
  clear #06070d
  color #38bdf8
  pen_width 3
  glow 0.8

  repeat 4 [
    fd 80
    rt 90
  ]
end

What each line does

  • mode 2d — Turns on smooth, anti-aliased vector graphics.
  • fx bloom(...) — Tells the hidden GPU shader to add a neon glow.
  • on frame(dt) — Runs 60 times every second to draw each frame.
  • repeat 4 [ ... ] — Repeats everything inside [ ] four times!
  • fd 80 / rt 90 — Move forward 80 units, turn right 90°.
⚡ Quick Challenge: Change repeat 4 to repeat 5 and rt 90 to rt 144 in the playground above. What shape do you get?
MISSION 02

Animation, Color & branch [ ... ]

Static drawings are cool, but games move! TurtleFX gives you a built-in time variable (seconds since start) and math waves like sin(time) that smoothly bounce between -1 and 1.

Even better: branch [ ... ] saves the turtle's position and angle before running a block, then snaps it right back when the block ends. That means you can draw a spinning wing or tree branch without messing up the rest of your drawing!

Spinning Rainbow Pinwheel 
mode 2d
fx bloom(strength: 0.6)

on frame(dt)
  clear #06070d
  rt time * 40           ; spin the whole wheel!

  repeat 12 with i [
    branch [
      rt i * 30          ; 12 spokes, 30° apart
      color hsl(i * 30 + time * 80, 100%, 60%)
      glow 0.7
      fd 70 + sin(time * 4 + i) * 25
      dot 8
    ]
  ]
end

Pro Tricks Unlocked

  • repeat 12 with i — Gives you a counter i from 0 to 11.
  • hsl(hue, 100%, 60%) — Cycles through the entire rainbow using degrees (0–360).
  • branch [ ... ] — Every spoke starts from the center because branch restores the turtle!
  • dot 8 — Stamps a glowing circle of radius 8 at the tip.
MISSION 03

Build a Retro Space Shooter (Lists & Collisions)

To destroy enemy ships in a game, you need two things: memory (which enemies are still alive?) and hitboxes (did my laser touch an enemy?).

In TurtleFX, you store multiple values in a list like let enemy_alive = [1, 1, 1, 1, 1, 1], and read or change item i using enemy_alive[i].

The Hit-Detection Loop from 01_retro_arcade.logo 
; 1 = alive, 0 = destroyed
let enemy_alive = [1, 1, 1, 1, 1, 1]

; Inside on frame(dt):
if enemy_alive[i] == 1 [
  if abs(laser_x - ex) < 9 and abs(laser_y - ey) < 8 [
    enemy_alive[i] = 0    ; destroy this enemy!
    laser_y = -20         ; reset the laser
    boom_t[i] = 0.35      ; trigger a 0.35s turtle explosion!
  ]
]

Why abs(laser_x - ex) < 9 works

abs(...) means absolute value (distance without caring about left/right sign). So abs(laser_x - ex) < 9 simply asks: "Is the laser within 9 pixels of the enemy horizontally?" If it's also within 8 pixels vertically, BOOM!

MISSION 04

Go 3D (And Turn It Into a GameBoy!)

Ready for 3D? You already know how! Just switch to mode 3d and add 3D turns: pitch (nose up/down), yaw (turn left/right), and roll (barrel roll).

Under the hood, TurtleFX switches to a 3D SDF Raymarching Shader—which gives you soft shadows, glowing crystals, smooth clay blending (smooth), and boolean hole-carving (carve).

Carve a Doorway & Grow a 3D Crystal Tree 
mode 3d
fx bloom(strength: 0.55)

; Stone arch with a carved-out doorway
at -2 1.4 0 [
  material matte(#94a3b8)
  box(2.1, 2.5, 0.85)
  carve [
    at -2 0.45 0 [ pitch 90  capsule(1.3, 0.62) ]
  ]
]
The 2-Line Retro GameBoy 3D Trick 
; Add these 2 lines to ANY 3D scene!
fx retro(320, 180, dither: bayer, palette: gameboy)
fx fog(color: #0f380f, near: 8, far: 22)

; Because all shaders share one post-FX pipeline,
; your 3D world instantly becomes dithered handheld 3D!
REFERENCE

Modern Logo Cheat Sheet

Turtle Moves

  • fd 50 / bk 50 — forward / back
  • rt 90 / lt 90 — right / left
  • pu / pd — pen up / pen down
  • pitch / yaw / roll — 3D turns

Shapes & Style

  • dot 10, rect 20 10
  • fill [ ... ] — filled polygon
  • color #ff004d or hsl(h, s, l)
  • pen_width 3, glow 0.8

3D Primitives

  • sphere(r), box(w, h, d)
  • capsule(len, r), torus(R, r)
  • smooth 0.5 [ ... ] — clay blend
  • carve [ ... ] — subtract shapes

Logic & Input

  • let x = 10, let arr = [1, 2, 3]
  • if key("space") [ ... ]
  • repeat 8 with i [ ... ]
  • branch [ ... ], at x y [ ... ]
